Experiment 1

Recognizing games from weights

We repeat the original weight-reading task with Astra and DeepSeek. Each model makes three independent attempts on each of four games, without tools.

Astra gets 12/12 right; DeepSeek gets 7/12. Both identify Breakout in all three attempts.

What is visible in the weights?

The task supplies a complete description of a 10×10 world: five input channels, five actions, and a 500 → 32 → 32 → 5 tanh network. All 17,253 parameters are provided as text. There are no candidate game names.

The observation layout makes a spatial reading possible. Reshaping the first layer produces 160 maps: five input channels × 32 hidden units. Each 10×10 map contains the connections from one channel to one hidden unit.

Agent-channel structure sits on the bottom playable row. Reward-channel structure is concentrated at the top. Moving-object and previous-frame channels cover the interior. The output layer emphasizes horizontal actions. Together these suggest a paddle, bricks and a moving ball.

All 160 first-layer maps

Recovering structure, missing the game

DeepSeek guesses Sokoban three times, Snake once and Asterix once. In its first Pac-Man answer, it reconstructs a symmetric maze but names Asterix with 88% confidence. Recovering spatial structure and identifying the task are distinct steps.

These small networks expose recognizable geometry. Naming the game also draws on familiar game concepts: weights and the interface description can suggest a behavior without uniquely identifying every rule.
